# Power BI Marketing Analytics Dashboard

This Power BI report presents the final visualisation stage of the End-to-End Marketing Analytics project. The dashboard brings together customer journey, social media engagement and customer review data to provide an interactive view of marketing performance.
The report contains four dashboard pages:

## 1. Overview

The Overview page provides a high-level summary of marketing performance across conversion, social media engagement and customer reviews.

Key metrics include:

- Overall conversion rate
- Total clicks
- Total likes
- Total views
- Average customer rating
- Monthly conversion trends
- Conversion rate by product
- Monthly social media engagement
- Product rating performance

[View Overview Dashboard](Screenshots/01_overview_dashboard.png)


## 2. Conversion Details

The Conversion Details page focuses on customer journey and conversion performance.

It includes:

- Overall conversion rate
- Customer journey stages from View to Purchase
- Monthly conversion trends
- Conversion rate by product
- Product-level monthly conversion analysis

[View Conversion Details Dashboard](Screenshots/02_conversion_details.png)



## 3. Social Media Details

The Social Media Details page analyses digital engagement across different content types and products.

The dashboard tracks:

- Views
- Clicks
- Likes
- Monthly engagement trends
- Views by content type
- Product-level engagement performance

[View Social Media Details Dashboard](Screenshots/03_social_media_details.png)

## 4. Customer Review Details

The Customer Review Details page combines customer ratings with the sentiment analysis performed in Python.

It includes:

- Average customer rating
- Distribution of ratings
- Number of reviews by sentiment category
- Monthly sentiment trends
- Individual customer review text
- Customer rating and sentiment analysis

[View Customer Review Details Dashboard](Screenshots/04_customer_review_details.png)

## Interactive Features

The report includes interactive filters for:

- Year
- Month
- Product
- Sentiment category

These filters allow users to explore marketing performance across different time periods, products and customer sentiment groups.

- Power BI Desktop
